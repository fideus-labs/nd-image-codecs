# nd-image-codecs

**This is a name placeholder.** The published JavaScript/TypeScript package for
nd-image-codecs is:

```sh
npm install @fideus-labs/nd-image-codecs
```

- npm: <https://www.npmjs.com/package/@fideus-labs/nd-image-codecs>
- Repository: <https://github.com/fideus-labs/nd-image-codecs>

nd-image-codecs is a family of composable Zarr v3 codecs for ND scientific
images (OME-Zarr / OME-NGFF): cross-axis lifting (`nd_lift`), HTJ2K coefficient
planes (`htj2k`), and ZFP blocks (`zfp`), assembled into a codec series from
an array's axis metadata.

This package under the unscoped name exists only to reserve the name and point
here. It has no code and no runtime dependency on the scoped package — install
`@fideus-labs/nd-image-codecs` instead.
